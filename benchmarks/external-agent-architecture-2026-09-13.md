# External Benchmark — Agent Architecture Research — 2026-09-13

**Type:** Strategic benchmark  
**Status:** CAPTURED → EXTRACTED → CANDIDATE  
**Scope:** PUB Core Holding  
**Corpus:** 19 YouTube videos supplied and reviewed during the 2026-09-13 research cycle

## Executive Finding

The external material does not demonstrate that PUB is fundamentally behind current agent architecture. It demonstrates that PUB's direction is broadly aligned with current practical patterns, while exposing a systems problem: capabilities are distributed across Neural, PDL, Antigravity, Codex, Claude Code, OpenClaw, Hermes, GitHub, Supabase and project-local context rather than exposed through one governed Holding runtime.

The priority is therefore **integration and operationalization**, not indiscriminate adoption of every tool mentioned by the market.

## Hype / Non-Adoption Signals

The research does not justify treating the following as architectural truths:

- arbitrary claims of 100x productivity;
- "fully autonomous company" as a blanket capability;
- agent-count as a proxy for intelligence;
- replacing agents entirely with Skills as a binary doctrine;
- replacing a governed knowledge system with a simple memory file;
- adopting a platform merely because it is popular in demonstrations.

## PUB Gaps Confirmed by Benchmark

1. Unified agent runtime / control plane.
2. Universal evaluation contract.
3. Unified tool registry and permission model.
4. Recovery/self-healing maturity.
5. Research Intelligence as a continuous capability.
6. Standard Skills lifecycle.
7. Observability across agent execution.
8. Stronger bridge between research findings and implementation.
