## 1. Architectural Principles & Hardening Guarantees

1. **Formal Nomenclature & State Classification:**
   - **CANONICAL (Authoritative Root of Truth):**
     $$\text{CANONICAL\_STATE} = \text{neural\_events} + \text{neural\_event\_parents} + \text{pub\_neural.source\_blobs}$$
     - `neural_events` (plus `neural_event_parents`) is the sole canonical state machine and mutation history.
     - Preserved immutable source blobs stored in external content-addressed storage (CAS) and registered in `pub_neural.source_blobs` are the canonical preserved evidence artifacts.
     - **`BLOB_DURABILITY_PRECONDITION = VERIFIED_BEFORE_CANONICAL_EVENT_COMMIT`**: Before accepting `SOURCE_INGESTED`, the blob must be persisted in external immutable write-once storage, its SHA-256 byte digest verified, and its manifest recorded in `pub_neural.source_blobs`.
     - **`BLOB_EVENT_ORDER = SOURCE_BLOB_VERIFIED_THEN_SOURCE_INGESTED`**: Manifest commitment precedes source ingestion:
       $$\text{external CAS verification} \to \text{authorized ingestion path} \to \text{SOURCE\_BLOB\_VERIFIED} \to \text{register\_verified\_blob} \to \text{SOURCE\_INGESTED}$$
       `SOURCE_INGESTED REQUIRES VERIFIED_SOURCE_BLOB`. The physical verification of the object occurs strictly outside PostgreSQL, while the database guarantees event authority, manifest consistency, cryptographic hash identity, and total monotonic ordering.
   - **DERIVED (Deterministic Projections):**
     - All graph projection tables (`neural_nodes`, `neural_edges`), provenance registries (`neural_sources`), evidence junctions (`neural_evidence`), and lexical search indexes (`neural_fts`) are strictly **derived projections**.
     - They can be dropped and deterministically reconstructed from canonical state under declared reducer versions.
   - **DERIVED AI (AI-Generated Artifacts):**
     - Semantic vector embeddings (`neural_vectors`) and hierarchical community summaries (`neural_community_reports`).
     - Rebuildable and versioned, carrying explicit generation lineage (`generation_id`, `graph_snapshot_hash`, `input_hash`, `model_id`, `prompt_version`, `temperature`).
   - **OPERATIONAL & GOVERNANCE:**
     - Checkpoint registries (`neural_projection_checkpoints`), webhook idempotency (`neural_idempotency_records`), schema version contracts (`neural_schema_versions`), and identity/session registries (`pub_neural.trusted_actors`, `pub_neural.active_sessions`).

2. **Event Identity, Sequence & Non-Forgeable Appends:**
   - **`EVENT_WRITE_AUTHORITY = CONTROLLED_APPEND_EVENT_PATH`**: Direct physical SQL `INSERT`, `UPDATE`, `DELETE`, and `TRUNCATE` on `neural_events` and `neural_event_parents` are completely **REVOKED** from application role `pub_neural_app`.
   - **`EVENT_IDENTITY = SERVER_RESOLVED_ACTOR`**: All event mutations MUST pass through the trusted `SECURITY DEFINER` function `pub_neural.append_event(...)`. The database resolves `SESSION_USER`, validates the transaction bearer session, verifies current status in `trusted_actors`, derives `actor_id` and `actor_role` server-side, and enforces event-type permissions. The application cannot forge caller identity.
   - **`GLOBAL_SEQUENCE = DATABASE_GENERATED`**: Total ordering is enforced via `global_sequence BIGINT GENERATED BY DEFAULT AS IDENTITY UNIQUE NOT NULL`. On empty database genesis bootstrap, the first event naturally receives `global_sequence = 1` and the sequence advances naturally to `2`.
   - **`EVENT_IMMUTABILITY = PHYSICALLY_ENFORCED`**: In addition to SQL privilege revocation, row-level modification blocking triggers (`pub_neural.prevent_event_mutation()`) physically abort any `UPDATE` or `DELETE` on canonical events.

3. **Sovereign & Privileged Event Type Protection:**
   - **`SOVEREIGN_EVENT_AUTHORITY = EXPLICIT`**:
     - `GENESIS_BOOTSTRAP` $\to$ Migration bootstrap only (strictly rejected in `append_event()`).
     - `SOURCE_BLOB_VERIFIED` $\to$ Controlled ingestion path (`INGESTOR` or `CEO` role only, with mandatory payload verification).
     - `DECISION_RATIFIED` $\to$ Sovereign CEO authority only (`actor_role = 'CEO'` and active in `trusted_actors`).
     - `GOVERNANCE_RULE_RATIFIED` $\to$ Sovereign CEO authority only (`actor_role = 'CEO'` and active in `trusted_actors`).
     - `ACTOR_REGISTERED`, `ACTOR_REVOKED` $\to$ Sovereign CEO governance authority only (`actor_role = 'CEO'`).
     - `pub_neural_admin` $\to$ Prohibited from appending runtime events (`ADMIN_AUTHORITY = INFRASTRUCTURE_ONLY_OR_REGISTERED_ACTOR`).

4. **Causal DAG & Concurrent Acyclicity Guarantee:**
   - Causal relationships between events are decoupled into `neural_event_parents`, supporting a true Directed Acyclic Graph (DAG) of predecessor events.
   - **`CAUSALITY_INVARIANT = DAG_NO_CYCLES`**: Cycle prevention ($A \to B \to C \to A$) is actively validated at write time via a recursive trigger function.
   - **`DAG_CONCURRENCY_GUARANTEE = TRANSACTION_ADVISORY_LOCK_SERIALIZED_VALIDATION`**: The trigger acquires `pg_advisory_xact_lock(hashtext('pub_neural_event_dag_lock'))` before running the recursive ancestor CTE. This serializes validation across concurrent writers while keeping readers non-blocking.

5. **Bi-Temporal Projections vs True Time-Travel Authority:**
   - **`TEMPORAL_HISTORY_AUTHORITY = EVENTS_PLUS_REPLAY`**: The sole canonical authority for institutional historical truth is `neural_events + replay`.
   - **`DERIVED_TEMPORAL_ACCELERATION`**: The columns `recorded_from` / `recorded_until` and `valid_from` / `valid_until` in `neural_nodes` and `neural_edges` constitute an indexed state projection for fast SQL query acceleration. They do **not** replace the event log as the audit source of truth. Projections may be dropped and rebuilt without loss of audit history.

6. **Scope Integrity Across Derived Projections (`SCOPE_INTEGRITY = FAIL_CLOSED`):**
   - Redundant security scope columns (`trust_zone`, `project_id`) across projections must never contradict the scope of their parent entities.
   - **`NO ARBITRARY CLIENT-SUPPLIED SCOPE`**: Any attempt to insert or project a divergent scope fails closed (`RAISE EXCEPTION`).
   - Enforced across all projections via dedicated server-side fail-closed validation triggers.

7. **Genesis / Bootstrap Trust Model (`GENESIS_AUTHORITY = EXPLICIT_GENESIS_BOOTSTRAP_EVENT`):**
   - **`GENESIS_STATE != NORMAL_RUNTIME_STATE`**: Migration `0001` initializes the root principal `actor:system:genesis` bound to a real, explicit bootstrap event `GENESIS_BOOTSTRAP` (`0191e4f0-0000-7000-8000-000000000001`::uuid, `global_sequence = 1`).
   - **`GENESIS_BOOTSTRAP = ONE_TIME_ONLY`**: The genesis actor establishes the sovereign CEO principal. Upon completing the migration bootstrap, `actor:system:genesis` is permanently revoked (`is_active = FALSE`, `revocation_reason = 'BOOTSTRAP_COMPLETE'`).
   - **`CEO_CREDENTIAL_PROVISIONING = OUT_OF_BAND_AND_REQUIRED`**: No real secrets or dummy/predictable hashes (e.g. empty string hash) are accepted. The deployment runner MUST supply a validated 64-character hex SHA-256 digest via session variable `pub_neural.bootstrap_ceo_credential_hash`. If absent or placeholder, migration fails closed immediately.

8. **Snapshot-Consistent Bearer Session RLS & Dynamic Role Authority:**
   - **`RLS_AUTHORITY = SESSION_USER_PLUS_SERVER_VALIDATED_BEARER_SESSION`**: The database never trusts unauthenticated client assertions or bare session variables.
   - **`CLIENT_GUC_AUTHORITY = NONE`**: A client GUC transports only an ephemeral token hash within a single transaction. It grants zero privilege on its own.
   - **`SESSION_AUTHORITY = CURRENT_TRUSTED_ACTOR_ROLE`**: Authorization evaluates the actor's current authoritative role and authorized trust zones in `trusted_actors`. If an actor is demoted or revoked mid-session, all existing sessions immediately lose elevated privileges.
   - **`CEO_AUTHORITY = DATABASE_ROLE_PLUS_ACTIVE_TRUSTED_ACTOR`**: Even the CEO database role `pub_neural_ceo` is subject to registry validation. Revoking `actor:ceo:sovereign` in `trusted_actors` immediately terminates all sovereign permissions and RLS clearances.
   - **`RLS_ACCESSOR = STABLE + SNAPSHOT_CONSISTENT`**: Accessor functions are strictly `STABLE` and use `CURRENT_TIMESTAMP` exclusively (never volatile `clock_timestamp()`), ensuring snapshot consistency during query execution.
   - **`EDGE_SECURITY = BOTH_ENDPOINTS_AUTHORIZED`**: An edge is visible if and only if the actor is authorized for both endpoint nodes (`source_node` AND `target_node`).
   - **`ROLE_SEPARATION = ADMIN / CEO / PROJECTOR / APP`**: Explicit privilege boundaries.
   - **`APPLICATION_BYPASSRLS = FALSE`**: `pub_neural_app` operates with `NOBYPASSRLS` and has `FORCE ROW LEVEL SECURITY` applied across all projection tables.
   - **`COMMUNITY_SCOPE = EXPLICIT`**: Community reports support both trust-zone-wide and project-scoped visibility.
   - **`STRICT CASCADE BOUNDARY`**: `ON DELETE CASCADE` is permitted strictly between derived projections. No foreign key on any derived projection or child table is permitted to cascade deletion into `neural_events`, `neural_event_parents`, or `pub_neural.source_blobs`.

- **Classification:** **CANONICAL CAUSAL GRAPH**


- **Concurrent-Safe Recursive Acyclicity Trigger Function:**
```sql
CREATE OR REPLACE FUNCTION pub_neural.check_event_dag_acyclicity()
RETURNS TRIGGER
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = pg_catalog, pub_neural, public
AS $$
BEGIN
    -- 1. Acquire transaction-level advisory lock on causal DAG insertions.
    PERFORM pg_advisory_xact_lock(hashtext('pub_neural_event_dag_lock'));

    -- 2. Prevent inserting edge (NEW.event_id -> NEW.parent_event_id)
    -- if parent_event_id can already reach event_id via ancestor traversal.
    IF EXISTS (
        WITH RECURSIVE ancestors AS (
            SELECT parent_event_id AS ancestor_id
            FROM pub_neural.neural_event_parents
            WHERE event_id = NEW.parent_event_id
            
            UNION
            
            SELECT p.parent_event_id
            FROM pub_neural.neural_event_parents p
            JOIN ancestors a ON p.event_id = a.ancestor_id
        )
        SELECT 1 FROM ancestors WHERE ancestor_id = NEW.event_id
    ) THEN
        RAISE EXCEPTION 'Causal cycle detected: event % is already an ancestor of parent %',
            NEW.event_id, NEW.parent_event_id;
    END IF;
    RETURN NEW;
END;
$$;

CREATE TRIGGER trg_neural_event_parents_acyclic
BEFORE INSERT ON neural_event_parents
FOR EACH ROW EXECUTE FUNCTION pub_neural.check_event_dag_acyclicity();
```

### 4.3 Canonical Table: `pub_neural.source_blobs` (Content-Addressed Blob Manifest)

- **Purpose:** Authoritative registry of immutable source content blobs preserved in external content-addressed storage.
- **Classification:** **CANONICAL MANIFEST OF IMMUTABLE SOURCE ARTIFACTS**
- **Durability Invariant:** **`BLOB_DURABILITY_PRECONDITION = VERIFIED_BEFORE_CANONICAL_EVENT_COMMIT`**.
  1. Blob bytes are persisted to external content-addressed storage (WORM retention);
  2. SHA-256 digest is verified against physical payload outside PostgreSQL;
  3. `SOURCE_BLOB_VERIFIED` event is published via `append_event()`;
  4. Manifest row in `pub_neural.source_blobs` is registered;
  5. Only then is `SOURCE_INGESTED` accepted into `neural_events`.
- **Security Boundary:** Direct DML is denied to `pub_neural_app`. Manifest registration occurs strictly via `pub_neural.register_verified_blob()`. Direct reading of `storage_uri` is denied; physical blob access occurs via `pub_neural.get_source_blob_access()`.

```sql
TABLE pub_neural.source_blobs (

    content_hash VARCHAR(64) NOT NULL,               -- Normalized content hash
```

- **Controlled Manifest Registration Procedure (`SECURITY DEFINER`):**
```sql
CREATE OR REPLACE FUNCTION pub_neural.register_verified_blob(
    p_file_sha256 VARCHAR(64),
    p_content_hash VARCHAR(64),
    p_storage_uri TEXT,
    p_storage_backend VARCHAR(32),
    p_byte_size BIGINT,
    p_mime_type VARCHAR(64),
    p_event_id UUID
) RETURNS VOID
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = pg_catalog, pub_neural, public
AS $$
DECLARE
    v_event pub_neural.neural_events%ROWTYPE;
    v_existing_blob pub_neural.source_blobs%ROWTYPE;
BEGIN
    -- 1. Fetch canonical event and verify existence
    SELECT * INTO v_event FROM pub_neural.neural_events WHERE id = p_event_id;
    IF NOT FOUND THEN
        RAISE EXCEPTION 'Blob registration failed: Originating event % does not exist', p_event_id;
    END IF;

    -- 2. Verify event type
    IF v_event.event_type <> 'SOURCE_BLOB_VERIFIED' THEN
        RAISE EXCEPTION 'Blob registration failed: Event % has type %, expected SOURCE_BLOB_VERIFIED', 
            p_event_id, v_event.event_type;
    END IF;

    -- 3. Verify that event actor had authority to verify blobs
    IF v_event.actor_role NOT IN ('INGESTOR', 'CEO') THEN
        RAISE EXCEPTION 'Blob registration failed: Event % was created by actor % with unauthorized role %',
            p_event_id, v_event.actor_id, v_event.actor_role;
    END IF;

    -- 4. Verify exact match between function parameters and canonical event payload
    IF (v_event.payload->>'file_sha256') <> p_file_sha256 THEN
        RAISE EXCEPTION 'Blob registration failed: file_sha256 mismatch (payload: %, param: %)',
            (v_event.payload->>'file_sha256'), p_file_sha256;
    END IF;

    IF (v_event.payload->>'storage_uri') <> p_storage_uri THEN
        RAISE EXCEPTION 'Blob registration failed: storage_uri mismatch (payload: %, param: %)',
            (v_event.payload->>'storage_uri'), p_storage_uri;
    END IF;

    IF (v_event.payload->>'byte_size')::BIGINT <> p_byte_size THEN
        RAISE EXCEPTION 'Blob registration failed: byte_size mismatch (payload: %, param: %)',
            (v_event.payload->>'byte_size'), p_byte_size;
    END IF;

    IF p_content_hash IS NOT NULL AND (v_event.payload->>'content_hash') IS NOT NULL THEN
        IF (v_event.payload->>'content_hash') <> p_content_hash THEN
            RAISE EXCEPTION 'Blob registration failed: content_hash mismatch (payload: %, param: %)',
                (v_event.payload->>'content_hash'), p_content_hash;
        END IF;
    END IF;

    -- 5. Safe idempotency check: if blob already registered with identical digest
    SELECT * INTO v_existing_blob FROM pub_neural.source_blobs WHERE file_sha256 = p_file_sha256;
    IF FOUND THEN
        IF v_existing_blob.storage_uri = p_storage_uri AND v_existing_blob.byte_size = p_byte_size THEN
            -- Identical blob already registered idempotently; return cleanly
            RETURN;
        ELSE
            RAISE EXCEPTION 'Integrity violation: Blob % is already registered with conflicting metadata', p_file_sha256;
        END IF;
    END IF;

    -- 6. Insert authoritative manifest record
    INSERT INTO pub_neural.source_blobs (
        file_sha256,
        content_hash,
        storage_uri,
        storage_backend,
        byte_size,
        mime_type,
        status,
        integrity_verified_at,
        created_at,
        originating_event_id
    ) VALUES (
        p_file_sha256,
        p_content_hash,
        p_storage_uri,
        p_storage_backend,
        p_byte_size,
        p_mime_type,
        'VERIFIED',
        CURRENT_TIMESTAMP,
        CURRENT_TIMESTAMP,
        p_event_id
    );
END;
$$;

REVOKE ALL ON FUNCTION pub_neural.register_verified_blob FROM PUBLIC;
GRANT EXECUTE ON FUNCTION pub_neural.register_verified_blob TO pub_neural_app;
```

- **Indexes:**
  - `idx_source_blobs_content_hash`: `(content_hash)`
  - `idx_source_blobs_event`: `(originating_event_id)`

### 4.4 Controlled Canonical Append Function (`pub_neural.append_event`)

> [!CRITICAL]
> **Zero Client Forgery Invariant:**
> Applications and agents are strictly forbidden from supplying arbitrary `actor_id` or `actor_role`.
> All events are appended through `pub_neural.append_event()`, which resolves identity server-side from the authenticated database session and active bearer session token.

```sql
CREATE OR REPLACE FUNCTION pub_neural.append_event(
    p_event_id UUID,
    p_event_type VARCHAR(64),
    p_stream_id VARCHAR(128),
    p_stream_version BIGINT,
    p_producer_version VARCHAR(32),
    p_payload JSONB,
    p_parent_event_ids UUID[] DEFAULT ARRAY[]::UUID[],
    p_signature TEXT DEFAULT NULL,
    p_event_version INTEGER DEFAULT 1,
    p_payload_schema_version INTEGER DEFAULT 1
) RETURNS BIGINT -- Returns the database-generated monotonic global_sequence
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = pg_catalog, pub_neural, public
AS $$
DECLARE
    v_token_hash VARCHAR(64);
    v_session pub_neural.active_sessions%ROWTYPE;
    v_actor pub_neural.trusted_actors%ROWTYPE;
    v_new_global_sequence BIGINT;
    v_parent_id UUID;
    v_source_blob_exists BOOLEAN;
BEGIN
    -- 1. Genesis event cannot be appended via runtime function
    IF p_event_type = 'GENESIS_BOOTSTRAP' THEN
        RAISE EXCEPTION 'Security violation: GENESIS_BOOTSTRAP cannot be appended via runtime API';
    END IF;

    -- 2. Resolve caller identity strictly through trusted_actors registry
    -- Path A: Native Sovereign CEO Database Connection (SESSION_USER = 'pub_neural_ceo')
    IF SESSION_USER = 'pub_neural_ceo' THEN
        SELECT * INTO v_actor
        FROM pub_neural.trusted_actors
        WHERE db_role = 'pub_neural_ceo'
          AND actor_role = 'CEO'
          AND is_active = TRUE;

        IF NOT FOUND THEN
            RAISE EXCEPTION 'Authorization failed: Sovereign CEO identity is not registered or has been revoked in trusted_actors';
        END IF;

    -- Path B: Dedicated Admin Role Prohibition (Option B: pub_neural_admin is infrastructure/migration only)
    ELSIF SESSION_USER = 'pub_neural_admin' THEN
        RAISE EXCEPTION 'Permission denied: pub_neural_admin is restricted exclusively to DDL, migrations, and maintenance. Runtime event appending is prohibited.';

    -- Path C: Standard Application Connection with Attached Bearer Session (pub_neural_app)
    ELSE
        v_token_hash := current_setting('pub_neural.active_session_token_hash', true);
        IF v_token_hash IS NULL OR v_token_hash = '' THEN
            RAISE EXCEPTION 'Authentication required: No bearer session attached to transaction';
        END IF;

        SELECT * INTO v_session
        FROM pub_neural.active_sessions
        WHERE session_token_hash = v_token_hash
          AND db_session_user = SESSION_USER
          AND expires_at > CURRENT_TIMESTAMP;

        IF NOT FOUND THEN
            RAISE EXCEPTION 'Authentication failed: Invalid, expired, or cross-connection session token';
        END IF;

        -- Validate against live registry: active status and role must strictly match
        SELECT * INTO v_actor
        FROM pub_neural.trusted_actors
        WHERE actor_id = v_session.actor_id
          AND db_role = SESSION_USER;

        IF NOT FOUND OR v_actor.is_active IS NOT TRUE OR v_actor.actor_role <> v_session.actor_role THEN
            RAISE EXCEPTION 'Authorization failed: Actor is inactive or role was modified (SESSION_AUTHORITY = CURRENT_TRUSTED_ACTOR_ROLE)';
        END IF;
    END IF;

    -- 3. Enforce Sovereign and Privileged Event Type Policies
    IF p_event_type IN ('DECISION_RATIFIED', 'GOVERNANCE_RULE_RATIFIED') AND v_actor.actor_role <> 'CEO' THEN
        RAISE EXCEPTION 'Authorization failed: Sovereign event type % requires active CEO role', p_event_type;
    END IF;

    IF p_event_type IN ('ACTOR_REGISTERED', 'ACTOR_REVOKED') AND v_actor.actor_role <> 'CEO' THEN
        RAISE EXCEPTION 'Authorization failed: Governance event % requires active CEO role', p_event_type;
    END IF;

    -- CONTROLLED_INGESTION_EVENT: SOURCE_BLOB_VERIFIED requires active INGESTOR or CEO role
    -- and validates payload structure
    IF p_event_type = 'SOURCE_BLOB_VERIFIED' THEN
        IF v_actor.actor_role NOT IN ('INGESTOR', 'CEO') THEN
            RAISE EXCEPTION 'Authorization failed: SOURCE_BLOB_VERIFIED requires INGESTOR or CEO role';
        END IF;
        IF p_payload->>'file_sha256' IS NULL OR p_payload->>'storage_uri' IS NULL OR p_payload->>'byte_size' IS NULL THEN
            RAISE EXCEPTION 'Malformed payload: SOURCE_BLOB_VERIFIED requires file_sha256, storage_uri, and byte_size';
        END IF;
    END IF;

    -- 4. Enforce Invariant: SOURCE_INGESTED requires previously verified blob manifest
    IF p_event_type = 'SOURCE_INGESTED' THEN
        IF v_actor.actor_role NOT IN ('INGESTOR', 'CEO') THEN
            RAISE EXCEPTION 'Authorization failed: SOURCE_INGESTED requires INGESTOR or CEO role';
        END IF;

        SELECT EXISTS (
            SELECT 1 FROM pub_neural.source_blobs 
            WHERE file_sha256 = (p_payload->>'file_sha256')
              AND status = 'VERIFIED'
        ) INTO v_source_blob_exists;

        IF NOT v_source_blob_exists THEN
            RAISE EXCEPTION 'Invariant violation: SOURCE_INGESTED requires verified source_blob manifest for hash %',
                (p_payload->>'file_sha256');
        END IF;
    END IF;

    -- 5. Insert event with server-derived actor_id and actor_role (Physical INSERT)
    INSERT INTO pub_neural.neural_events (
        id,
        event_type,
        event_version,
        payload_schema_version,
        producer_version,
        stream_id,
        stream_version,
        actor_id,
        actor_role,
        payload,
        signature,
        recorded_at
    ) VALUES (
        p_event_id,
        p_event_type,
        p_event_version,
        p_payload_schema_version,
        p_producer_version,
        p_stream_id,
        p_stream_version,
        v_actor.actor_id,
        v_actor.actor_role,
        p_payload,
        p_signature,
        CURRENT_TIMESTAMP
    ) RETURNING global_sequence INTO v_new_global_sequence;

    -- 6. Insert parent causal links if provided
    IF cardinality(p_parent_event_ids) > 0 THEN
        FOREACH v_parent_id IN ARRAY p_parent_event_ids LOOP
            INSERT INTO pub_neural.neural_event_parents (event_id, parent_event_id, created_at)
            VALUES (p_event_id, v_parent_id, CURRENT_TIMESTAMP);
        END LOOP;
    END IF;

    RETURN v_new_global_sequence;
END;
$$;

REVOKE ALL ON FUNCTION pub_neural.append_event FROM PUBLIC;
GRANT EXECUTE ON FUNCTION pub_neural.append_event TO pub_neural_app;
```

## 5. Scope Integrity Matrix & Core Projections

### 5.0 Scope Integrity Matrix (`SCOPE_INTEGRITY = FAIL_CLOSED`)

Redundant scope columns (`trust_zone`, `project_id`) are maintained on projections for zero-join RLS and query acceleration. To guarantee that no derived projection record contradicts its parent canonical state:

| Projection | Scope Source Entity | Enforcement Mechanism | Failure Mode |
|---|---|---|---|
| `neural_sources` | Ingestion event payload | Server-side trigger `check_source_scope_integrity()` | Abort transaction on scope mismatch |
| `neural_nodes` | Extraction event payload | Reducer invariant + Check constraints | Abort transaction on invalid scope |
| `neural_edges` | Both endpoint nodes | Server-side trigger `check_edge_scope_integrity()` | Abort transaction if edge zone contradicts nodes |
| `neural_evidence` | Target entity (`node` or `edge`) | Server-side trigger `check_evidence_scope_integrity()` | Abort transaction if scope diverges from target |
| `neural_vectors` | Target entity (`NODE`, `EVIDENCE`, `COMMUNITY`)| Server-side trigger `check_vector_scope_integrity()` | Abort transaction if target missing or divergent |
| `neural_fts` | Associated `node` | Server-side trigger `check_fts_scope_integrity()` | Abort transaction if scope diverges from node |
| `neural_community_reports` | Generation clustering run | Reducer invariant + explicit RLS | Abort transaction on invalid generation scope |

```sql
RETURNS TRIGGER
LANGUAGE plpgsql
```

```sql
SET search_path = pg_catalog, pub_neural, public
AS $$
DECLARE
    v_src_zone VARCHAR(64);

    END IF;
    RETURN NEW;
END;
$$;
```

### 6.1 Vector Projection: `neural_vectors` (Fixed 1536-Dim Contract + RLS)

```sql
TABLE neural_vectors (
```

## 8. Database Security, Roles & Privilege Hardening

`ROLE_SEPARATION = ADMIN / CEO / PROJECTOR / APP`. To enforce immutability and physical isolation at the database layer, PUB Neural mandates four distinct PostgreSQL database roles:

### 8.1 Migration / Admin Role (`pub_neural_admin`)
- Used exclusively by automated CI/CD deployment pipelines and administrative maintenance runbooks.
- Owns the `pub_neural` schema and all database objects.
- Granted `BYPASSRLS` for running DDL migrations, index maintenance, and backup routines.
- **Architectural Exception (ALLOWED):** `BYPASSRLS` is permitted strictly for DDL migrations and administrative operations.
- **Strict Prohibition (Option B Enforcement):** NEVER used for application runtime, API traffic, or runtime event authoring. `append_event()` strictly rejects execution when `SESSION_USER = 'pub_neural_admin'`.

### 8.2 Sovereign Authority Role (`pub_neural_ceo`)
- The sovereign connection identity used by the CEO / Root Principal.
- Authenticated via dedicated sovereign database credentials or mTLS client certificate (`SESSION_USER = 'pub_neural_ceo'`).
- **`CEO_AUTHORITY = DATABASE_ROLE_PLUS_ACTIVE_TRUSTED_ACTOR`**: Direct database role membership alone does NOT grant sovereign powers. All operations (`append_event()`, `verify_actor_access()`) verify that `trusted_actors` contains an active record where `db_role = 'pub_neural_ceo'`, `actor_role = 'CEO'`, and `is_active = TRUE`. If this record is revoked (`is_active = FALSE`), all permissions and RLS clearances immediately terminate.
- Authorized to publish sovereign ratification events (`DECISION_RATIFIED`, `GOVERNANCE_RULE_RATIFIED`, `ACTOR_REGISTERED`, `ACTOR_REVOKED`).

### 8.3 Projector Role (`pub_neural_projector`)
- The background connection identity used by reducers, projector workers, and indexers.
- Runs exclusively on an isolated internal network. Accepts NO external agent connections.
- Granted `BYPASSRLS` or dedicated projector clearance to read `neural_events` and write derived projections.
- Prohibited from modifying `neural_events` (`UPDATE`, `DELETE`, `TRUNCATE` are revoked).

### 8.4 Application / Agent Role (`pub_neural_app`)
- The connection identity used by API servers, webhooks, and agent integrations.
- **`APPLICATION_BYPASSRLS = FALSE`**: Does NOT possess `BYPASSRLS`.
- **`neural_events` & `neural_event_parents`:** Direct `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE` are completely **REVOKED**.
- **`pub_neural.append_event()`:** Permitted append execution path with server-side identity derivation.
- **`pub_neural.source_blobs`:** Direct `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE` are completely **REVOKED**.
- **`pub_neural.trusted_actors` & `pub_neural.active_sessions`:** Direct access is completely **REVOKED**.
- **Derived Projections:** `SELECT` ONLY, strictly governed by `FORCE ROW LEVEL SECURITY`.

### 9.1 The Bearer Token Lifecycle Across Transaction Boundaries

In PostgreSQL, `SET LOCAL` is transaction-scoped and is automatically wiped upon `COMMIT`. Therefore, **`SET LOCAL` cannot be used to persist session authentication across transactions**.

To support connection pooling (e.g. transaction pooling) and robust multi-transaction agent lifecycles:
1. **Token Issuance:** The agent authenticates once via `pub_neural.establish_session_context(...)`, which validates its machine secret against `pub_neural.trusted_actors` and returns an unguessable 256-bit raw bearer token.
2. **Client-Side Token Retention:** The application / agent holds the raw bearer token in memory.
3. **Per-Transaction Attachment:** When initiating a database transaction, the application issues `SELECT pub_neural.attach_session(p_bearer_token);`.
4. **Transaction-Local Setting:** The function verifies the token against `pub_neural.active_sessions`, current `SESSION_USER`, and active role in `trusted_actors`. If valid, it binds `pub_neural.active_session_token_hash` for that transaction (`is_local = true`).
5. **Snapshot-Consistent Evaluation:** RLS queries evaluate `pub_neural.verify_actor_access()`. If no token was attached, or if the token expired relative to `CURRENT_TIMESTAMP`, access is unconditionally denied.

### 9.2 Controlled Context Establishment (`SECURITY DEFINER`)

```sql
CREATE OR REPLACE FUNCTION pub_neural.establish_session_context(
    p_actor_id VARCHAR(128),
    p_machine_secret TEXT,
    p_requested_trust_zone VARCHAR(64),
    p_requested_project VARCHAR(64) DEFAULT NULL
) RETURNS TEXT -- Returns the opaque raw bearer token to the caller
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = pg_catalog, pub_neural, public
AS $$
DECLARE
    v_actor_role neural_actor_role;
    v_authorized_zones TEXT[];
    v_authorized_projects TEXT[];
    v_credential_identity VARCHAR(64);
    v_raw_token TEXT;
    v_token_hash VARCHAR(64);
BEGIN
    -- 1. Validate actor against trusted_actors registry
    SELECT actor_role, authorized_trust_zones, authorized_projects, credential_identity
    INTO v_actor_role, v_authorized_zones, v_authorized_projects, v_credential_identity
    FROM pub_neural.trusted_actors
    WHERE actor_id = p_actor_id 
      AND is_active = TRUE
      AND db_role = SESSION_USER;

    IF NOT FOUND THEN
        RAISE EXCEPTION 'Authentication failed: Invalid, revoked, or role-mismatched actor %', p_actor_id;
    END IF;

    -- 2. Verify high-entropy machine secret via SHA-256 digest comparison
    IF encode(sha256(p_machine_secret::bytea), 'hex') <> v_credential_identity THEN
        RAISE EXCEPTION 'Authentication failed: Invalid machine secret for actor %', p_actor_id;
    END IF;

    -- 3. Validate requested trust zone clearance
    IF NOT (p_requested_trust_zone = ANY(v_authorized_zones)) AND v_actor_role <> 'CEO' THEN
        RAISE EXCEPTION 'Authorization failed: Actor not cleared for trust zone %', p_requested_trust_zone;
    END IF;

    -- 4. Validate requested project clearance if scoped
    IF p_requested_project IS NOT NULL AND cardinality(v_authorized_projects) > 0 THEN
        IF NOT (p_requested_project = ANY(v_authorized_projects)) AND v_actor_role <> 'CEO' THEN
            RAISE EXCEPTION 'Authorization failed: Actor not cleared for project %', p_requested_project;
        END IF;
    END IF;

    -- 5. Generate high-entropy 256-bit unguessable raw token
    v_raw_token := encode(gen_random_bytes(32), 'hex');
    v_token_hash := encode(sha256(v_raw_token::bytea), 'hex');

    -- 6. Register active session with 1-hour expiration
    INSERT INTO pub_neural.active_sessions (
        session_token_hash,
        actor_id,
        actor_role,
        active_trust_zone,
        active_project_id,
        db_session_user,
        authenticated_at,
        expires_at
    ) VALUES (
        v_token_hash,
        p_actor_id,
        v_actor_role,
        p_requested_trust_zone,
        p_requested_project,
        SESSION_USER,
        CURRENT_TIMESTAMP,
        CURRENT_TIMESTAMP + interval '1 hour'
    );

    -- Return raw bearer token to client
    RETURN v_raw_token;
END;
$$;

REVOKE ALL ON FUNCTION pub_neural.establish_session_context(VARCHAR, TEXT, VARCHAR, VARCHAR) FROM PUBLIC;
GRANT EXECUTE ON FUNCTION pub_neural.establish_session_context(VARCHAR, TEXT, VARCHAR, VARCHAR) TO pub_neural_app;
```

### 9.3 Transaction Session Attachment Function (`pub_neural.attach_session`)

Called by application workers at the beginning of each transaction:

```sql
CREATE OR REPLACE FUNCTION pub_neural.attach_session(
    p_bearer_token TEXT
) RETURNS BOOLEAN
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = pg_catalog, pub_neural, public
AS $$
DECLARE
    v_token_hash VARCHAR(64);
    v_actor_active BOOLEAN;
    v_current_role neural_actor_role;
    v_session_role neural_actor_role;
BEGIN
    IF p_bearer_token IS NULL OR p_bearer_token = '' THEN
        RETURN FALSE;
    END IF;

    v_token_hash := encode(sha256(p_bearer_token::bytea), 'hex');

    -- Validate that session exists, is active, matches current SESSION_USER,
    -- actor is active, and session role matches actor's CURRENT authoritative role
    SELECT s.actor_role, a.is_active, a.actor_role 
    INTO v_session_role, v_actor_active, v_current_role
    FROM pub_neural.active_sessions s
    JOIN pub_neural.trusted_actors a ON s.actor_id = a.actor_id
    WHERE s.session_token_hash = v_token_hash
      AND s.db_session_user = SESSION_USER
      AND s.expires_at > CURRENT_TIMESTAMP;

    IF v_actor_active IS NOT TRUE OR v_session_role <> v_current_role THEN
        RETURN FALSE; -- Session invalid or actor role demoted/changed
    END IF;

    -- Attach validated hash to transaction-local config
    PERFORM set_config('pub_neural.active_session_token_hash', v_token_hash, true);
    RETURN TRUE;
END;
$$;

REVOKE ALL ON FUNCTION pub_neural.attach_session(TEXT) FROM PUBLIC;
GRANT EXECUTE ON FUNCTION pub_neural.attach_session(TEXT) TO pub_neural_app;
```

### 9.4 Protected Authorization Accessor Function (`verify_actor_access`)

Evaluates RLS row authorization. Strictly `STABLE`, evaluates all timestamps against `CURRENT_TIMESTAMP`, and enforces `SESSION_AUTHORITY = CURRENT_TRUSTED_ACTOR_ROLE`:

```sql
CREATE OR REPLACE FUNCTION pub_neural.verify_actor_access(
    p_target_trust_zone VARCHAR(64),
    p_target_project_id VARCHAR(64) DEFAULT NULL
) RETURNS BOOLEAN
LANGUAGE plpgsql
STABLE
SECURITY DEFINER
SET search_path = pg_catalog, pub_neural, public
AS $$
DECLARE
    v_token_hash VARCHAR(64);
    v_session pub_neural.active_sessions%ROWTYPE;
    v_actor pub_neural.trusted_actors%ROWTYPE;
BEGIN
    -- Check 1: Sovereign CEO Role Clearance
    -- CEO_AUTHORITY = DATABASE_ROLE_PLUS_ACTIVE_TRUSTED_ACTOR_RECORD
    -- A connection as pub_neural_ceo ONLY receives global clearance if trusted_actors confirms active CEO status
    IF SESSION_USER = 'pub_neural_ceo' THEN
        SELECT * INTO v_actor
        FROM pub_neural.trusted_actors
        WHERE db_role = 'pub_neural_ceo'
          AND actor_role = 'CEO'
          AND is_active = TRUE;

        IF FOUND THEN
            RETURN TRUE; -- Authorized active CEO principal
        ELSE
            RETURN FALSE; -- Revoked or missing CEO record: DENIED even if DB connection exists
        END IF;
    END IF;

    -- Check 2: Projector Role (Internal reducer background worker read clearance)
    IF SESSION_USER = 'pub_neural_projector' THEN
        RETURN TRUE;
    END IF;

    -- Note on pub_neural_admin: Admin role is infrastructure-only and has BYPASSRLS for DDL/migrations.
    -- App traffic never connects as pub_neural_admin.

    -- Check 3: Read transaction-attached token hash
    v_token_hash := current_setting('pub_neural.active_session_token_hash', true);
    IF v_token_hash IS NULL OR v_token_hash = '' THEN
        RETURN FALSE; -- No session attached to this transaction: DENIED
    END IF;

    -- Check 4: Look up token hash in protected active_sessions table for current SESSION_USER
    SELECT * INTO v_session
    FROM pub_neural.active_sessions
    WHERE session_token_hash = v_token_hash
      AND db_session_user = SESSION_USER
      AND expires_at > CURRENT_TIMESTAMP;

    IF NOT FOUND THEN
        RETURN FALSE; -- Expired, invalid, or cross-connection token: DENIED
    END IF;

    -- Check 5: Verify that the actor remains active and current role matches session role
    SELECT * INTO v_actor
    FROM pub_neural.trusted_actors
    WHERE actor_id = v_session.actor_id;

    IF NOT FOUND OR v_actor.is_active IS NOT TRUE OR v_actor.actor_role <> v_session.actor_role THEN
        RETURN FALSE; -- Actor revoked or role modified mid-session: DENIED
    END IF;

    -- Check 6: Sovereign CEO Actor Role clearance
    IF v_actor.actor_role = 'CEO' THEN
        RETURN TRUE;
    END IF;

    -- Check 7: Trust Zone Verification against current authorization
    IF v_session.active_trust_zone <> p_target_trust_zone 
       OR NOT (p_target_trust_zone = ANY(v_actor.authorized_trust_zones)) THEN
        RETURN FALSE; -- Trust zone mismatch or revoked: DENIED
    END IF;

    -- Check 8: Project Scope Verification (if projection record is project-scoped)
    IF p_target_project_id IS NOT NULL AND v_session.active_project_id IS NOT NULL THEN
        IF v_session.active_project_id <> p_target_project_id THEN
            RETURN FALSE; -- Project scope mismatch: DENIED
        END IF;
    END IF;

    RETURN TRUE;
END;
$$;

REVOKE ALL ON FUNCTION pub_neural.verify_actor_access(VARCHAR, VARCHAR) FROM PUBLIC;
GRANT EXECUTE ON FUNCTION pub_neural.verify_actor_access(VARCHAR, VARCHAR) TO pub_neural_app, pub_neural_projector;
```

### 9.5 Edge Authorization Accessor Function (`verify_edge_access`)

Enforces `EDGE_SECURITY = BOTH_ENDPOINTS_AUTHORIZED`. An edge is visible if and only if the actor is authorized for both endpoint nodes:

```sql
CREATE OR REPLACE FUNCTION pub_neural.verify_edge_access(
    p_source_id VARCHAR(128),
    p_target_id VARCHAR(128),
    p_edge_trust_zone VARCHAR(64)
) RETURNS BOOLEAN
LANGUAGE plpgsql
STABLE
SECURITY DEFINER
SET search_path = pg_catalog, pub_neural, public
AS $$
DECLARE
    v_src_zone VARCHAR(64);
    v_src_project VARCHAR(64);
    v_tgt_zone VARCHAR(64);
    v_tgt_project VARCHAR(64);
BEGIN
    -- Check edge trust zone clearance first
    IF NOT pub_neural.verify_actor_access(p_edge_trust_zone, NULL) THEN
        RETURN FALSE;
    END IF;

    -- Fetch source node scope
    SELECT trust_zone, project_id INTO v_src_zone, v_src_project
    FROM pub_neural.neural_nodes WHERE id = p_source_id;

    IF v_src_zone IS NULL OR NOT pub_neural.verify_actor_access(v_src_zone, v_src_project) THEN
        RETURN FALSE;
    END IF;

    -- Fetch target node scope
    SELECT trust_zone, project_id INTO v_tgt_zone, v_tgt_project
    FROM pub_neural.neural_nodes WHERE id = p_target_id;

    IF v_tgt_zone IS NULL OR NOT pub_neural.verify_actor_access(v_tgt_zone, v_tgt_project) THEN
        RETURN FALSE;
    END IF;

    RETURN TRUE;
END;
$$;

REVOKE ALL ON FUNCTION pub_neural.verify_edge_access(VARCHAR, VARCHAR, VARCHAR) FROM PUBLIC;
GRANT EXECUTE ON FUNCTION pub_neural.verify_edge_access(VARCHAR, VARCHAR, VARCHAR) TO pub_neural_app, pub_neural_projector;
```

### 9.6 Source Blob Accessor Function (`get_source_blob_access`)

Prevents `pub_neural.source_blobs` from becoming an oracle or leaking physical storage URIs across trust zones:

```sql
CREATE OR REPLACE FUNCTION pub_neural.get_source_blob_access(
    p_file_sha256 VARCHAR(64)
) RETURNS TABLE (
    file_sha256 VARCHAR(64),
    content_hash VARCHAR(64),
    storage_uri TEXT,
    storage_backend VARCHAR(32),
    byte_size BIGINT,
    mime_type VARCHAR(64)
)
LANGUAGE plpgsql
STABLE
SECURITY DEFINER
SET search_path = pg_catalog, pub_neural, public
AS $$
BEGIN
    -- Verify that caller has access to at least one authorized neural_sources record referencing this blob
    IF NOT EXISTS (
        SELECT 1 FROM pub_neural.neural_sources s
        WHERE s.file_sha256 = p_file_sha256
          AND pub_neural.verify_actor_access(s.trust_zone, s.project_id)
    ) THEN
        RAISE EXCEPTION 'Access denied: Actor not authorized for any source referencing blob %', p_file_sha256;
    END IF;

    RETURN QUERY
    SELECT b.file_sha256, b.content_hash, b.storage_uri, b.storage_backend, b.byte_size, b.mime_type
    FROM pub_neural.source_blobs b
    WHERE b.file_sha256 = p_file_sha256;
END;
$$;

REVOKE ALL ON FUNCTION pub_neural.get_source_blob_access(VARCHAR) FROM PUBLIC;
GRANT EXECUTE ON FUNCTION pub_neural.get_source_blob_access(VARCHAR) TO pub_neural_app, pub_neural_projector;
```

## 10. Rebuild Contract: Deterministic Derived State vs AI Artifacts

The system guarantees that derived state can be completely dropped and reconstructed:

$$\text{Replay: } (\text{neural\_events} + \text{pub\_neural.source\_blobs}) \xrightarrow[\text{normalization rules}]{\text{reducer\_version} + \text{projection\_version}} \text{Deterministic Derived State}$$

| Component Class | Target Tables | Rebuild Condition & Reproducibility Guarantee |
|---|---|---|
| **Deterministic Projections** | `neural_nodes`, `neural_edges`, `neural_evidence`, `neural_sources`, `neural_fts` | **Deterministic Projection Reproducibility:** Replaying `neural_events` ordered strictly by `global_sequence ASC` with access to preserved immutable source blobs in `pub_neural.source_blobs` under: (1) same event sequence, (2) same `reducer_version`, (3) same `projection_version`, (4) same normalization rules, and (5) same deterministic processing order produces identical projection states. |
| **Derived AI Artifacts** | `neural_vectors`, `neural_community_reports` | **Versioned Rebuildability:** Rebuildable from source text and events. They are version-tracked artifacts and do NOT carry a universal bit-identical guarantee. Reproducible strictly under the identical declared model checkpoint, prompt template, tokenizer, and decoding configuration (temperature = 0). |

## 11. Foreign Key Integrity Rules & Strict CASCADE Boundary

Foreign keys adhere strictly to the principle that **Event Log is Canonical** and **Projections are Rebuildable**:

> [!CRITICAL]
> **Strict CASCADE Boundary Rule:**
> `ON DELETE CASCADE` is **strictly permitted only between derived projections**.
> **No foreign key on any derived projection or child table is permitted to CASCADE into `neural_events`, `neural_event_parents`, or `pub_neural.source_blobs`**.
> `neural_events` and `source_blobs` are permanently protected by `ON DELETE RESTRICT` and role-enforced append-only permissions.

- **References to Canonical Events (`neural_events`) & Blobs (`source_blobs`):**
  - All projection foreign keys referencing `neural_events(id)` (`originating_event_id`, `last_transition_event_id`, etc.) use **`ON DELETE RESTRICT`**. Events cannot be deleted.
  - Foreign keys referencing `pub_neural.source_blobs(file_sha256)` use **`ON DELETE RESTRICT`**. Preserved blobs cannot be unlinked or purged while referenced.
- **References Between Derived Projections:**
  - `neural_evidence` → `neural_sources`: **`ON DELETE RESTRICT`** (a source cannot be pruned if active evidence references it).
  - `neural_edges` → `neural_nodes`: **`ON DELETE RESTRICT`** (nodes cannot be dropped if active edges connect to them).
  - `neural_evidence` → `neural_nodes` / `neural_edges`: **`ON DELETE CASCADE`** (when a derived node or edge is deleted or wiped during projection re-indexing, its dependent evidence link drops cleanly with it).
  - `neural_fts` → `neural_nodes`: **`ON DELETE CASCADE`**.
  - `superseded_by` self-references on nodes/edges: **`ON DELETE RESTRICT`** (preserves the historical supersession audit chain).
