## Architectural synthesis

### 1. Agent workforce
Paperclip + Hermes Bots + Agency Agents + Maestri point toward a workforce layer: persistent specialists, explicit roles, group coordination, scheduled routines, cross-machine execution and visual observability.

### 2. Agent engineering context
Graft + Headroom + codebase-memory-mcp point toward a context layer: code graphs, retrieval, compression, shared memory and learned corrections. PUB Neural remains the institutional source of truth; these tools are candidates for technical primitives, not replacements for Neural.

### 3. Tool/action layer
Composio + MCP + Hermes integrations point toward a tool gateway. PDL should evaluate whether a unified capability registry is useful without creating unnecessary vendor coupling.

### 4. Lead intelligence
Google Maps Scraper Kit + Scrapling + Buscando 1 Milhão form a a concrete PUB Leads research track: discovery -> enrichment -> qualification -> outreach, with rate limits, opt-out, claims verification and cost controls as first-class constraints.

### 5. Structured execution
Outlines suggests enforcing typed/structured agent contracts at generation time rather than relying only on post-generation parsing. This may strengthen PDL task plans, tool calls and validation artifacts.

### 6. Simulation / spatial intelligence
MiroFish, God's Eye View and Agentville are research tracks for simulation, spatial observation and agent-world interfaces. They should remain separate from core PDL implementation until a concrete PUB use case is validated.

## Non-negotiable research rule

Do not copy projects wholesale. For each candidate, perform: Observe -> Benchmark -> Gap analysis -> Small isolated proof -> Validate -> Decide -> Implement -> Institutionalize in PUB Neural.
