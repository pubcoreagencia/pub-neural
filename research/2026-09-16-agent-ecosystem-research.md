## Architectural synthesis

### 1. Agent workforce
Paperclip + Hermes Bots + Agency Agents + Maestri point toward a workforce layer: persistent specialists, explicit roles, group coordination, scheduled routines, cross-machine execution and visual observability.

### 2. Agent engineering context
Graft + Headroom + codebase-memory-mcp point toward a context layer: code graphs, retrieval, compression, shared memory and learned corrections. PUB Neural remains the institutional source of truth; these tools are candidates for technical primitives, not replacements for Neural.

### 3. Agent operating system / harness
ECC + teamai-cli + Skills + Ponytail + PI-Desktop suggest a stronger engineering harness around the agents: reusable skills, explicit rules, security controls, research-first execution, minimal-change behavior, session/workspace management and portable team configuration.

### 4. Tool/action and model-routing layer
Composio + MCP + Hermes integrations + Omni Route point toward a capability gateway and provider-routing layer. PDL should evaluate whether a unified capability registry, fallback policy and provider abstraction reduce operational friction without creating unnecessary coupling.

### 5. Knowledge-to-skill pipeline
Open Notebook + Book to Skill + PUB Neural suggest a pipeline from external sources to durable institutional capability: ingest -> retrieve -> distill -> validate -> package as skill/rule/lesson -> institutionalize.

### 6. Lead intelligence
Google Maps Scraper Kit + Scrapling + Buscando 1 Milhão + OpenSEO form a a concrete PUB Leads research track: discovery -> enrichment -> qualification -> SEO intelligence -> outreach, with rate limits, opt-out, claims verification and cost controls as first-class constraints.

### 7. Structured engineering communication
Outlines + I Have ADHD + No AI Slop + diagram-design suggest a communication-quality layer: typed outputs, action-first responses, cleaner prose and deterministic visual artifacts. These should be evaluated as skills/policies rather than hard-coded assumptions in the core runtime.

### 8. Simulation / spatial / media intelligence
MiroFish, God's Eye View, Agentville, VoiceStudio and Open Generative AI remain research tracks for simulation, spatial observation, voice and generative media. They should remain separate from core PDL implementation until a concrete PUB use case is validated.

## Non-negotiable research rule

Do not copy projects wholesale. For each candidate, perform: Observe -> Benchmark -> Gap analysis -> Small isolated proof -> Validate -> Decide -> Implement -> Institutionalize in PUB Neural.
